# Prompt Manager

## 프로그램 소개

이 프로그램은 자주 사용하는 프롬프트를 등록하고 관리하기 위한 Python 콘솔 프로그램입니다.
프롬프트를 추가하고, 목록·카테고리·검색·상세 보기 기능을 이용할 수 있으며 즐겨찾기로 필요한 프롬프트를 따로 관리할 수 있습니다.

## 실행 방법

1. VS Code에서 프로젝트 폴더를 엽니다.
2. 터미널을 엽니다.
3. 터미널에 `python prompt_manager.py`를 입력하고 Enter를 누릅니다.
4. 프로그램이 실행되면 원하는 메뉴 번호를 입력합니다.

## 주요 기능

1. 프롬프트 추가
2. 전체 프롬프트 목록 보기
3. 카테고리별 프롬프트 조회
4. 제목 또는 내용으로 프롬프트 검색
5. 프롬프트 상세 보기
6. 즐겨찾기 추가 및 해제
7. 즐겨찾기된 프롬프트 목록 보기

## 등록된 프롬프트 카테고리

- 페르소나: 특정 역할이나 관점을 설정하는 프롬프트
- 텍스트 생성: 교육과정, 학습자료 등 텍스트를 생성하는 프롬프트
- 자동화: 반복적인 작업이나 학습자료 생성을 자동화하기 위한 프롬프트
